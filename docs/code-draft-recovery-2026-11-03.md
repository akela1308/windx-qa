# Восстановление несохранённого кода, 3 ноября 2026

## Выбранный пробел

После последней проверки изображений следующий самостоятельный этап закрывает потерю ввода HTML/CSS/JS. Предупреждение об уходе уже было, но повторное открытие редактора не восстанавливало неподготовленную правку. Этот пробел был указан в сквозном аудите 2 ноября.

## Сделано

- Вкладка «Код» сохраняет ввод в localStorage при изменении поля: название, HTML, CSS, JavaScript, высоты и место вставки. Запрос к AI или серверу при этом не отправляется.
- Ключ включает аккаунт и сайт. При переходе между сайтами/аккаунтами компонент переинициализируется. Гостям редактирование кода по-прежнему недоступно.
- При повторном открытии требуется явный выбор: восстановить ввод или удалить локальную копию. Сохранённый код показывается экранированным текстом в read-only полях, не исполняется.
- Восстановление разрешено только для той же версии сайта и существующего выбранного блока. Для другой версии остаются просмотр и ручное копирование: старый индекс не переносится в новый раздел автоматически.
- После восстановления действуют прежние серверные ограничения, просмотр изменений, применение в черновик и отдельная публикация.
- При успешной подготовке собственного серверного предложения локальная копия очищается: предложение уже хранится на сервере. Чужое предложение, например AI-правка, локальный код не удаляет.
- Есть сброс текущего ввода. Смена кодового раздела после подтверждённого отказа от правки удаляет старую локальную копию. При обычном уходе на другую вкладку объясняется возможность восстановления.
- Выход через меню аккаунта очищает только локальные черновики WINDX. Настройки браузера и другие данные не удаляются.
- Запрет или переполнение хранилища показывается явным предупреждением. Обычная работа с кодом остаётся доступной.
- Тексты доступны на английском, русском и испанском.

## Границы

Это одна локальная копия ввода кода на аккаунт и сайт в данном браузере, с допустимым сроком восстановления 7 дней. Истёкшие и повреждённые записи удаляются при следующем чтении. Очистка данных браузера или выход удаляет копию. Между компьютерами она не переносится; одновременная работа нескольких вкладок не объединяется, последняя запись заменяет предыдущую. Это не версия сайта и не резерв инфраструктуры.

Функция касается вкладки «Код». Автосохранение неприменённого текста обычных секций, AI-запросов и всего состояния свободного холста этим этапом не заявляется. Пароли, ключи и персональные данные посетителей в код добавлять нельзя, прежнее предупреждение сохранено. Браузерное хранилище не является сейфом для секретов.

Тарифы, Google-вход, внешний домен, юридические документы платформы и регулярное сопровождение не изменялись. Рабочие сайты и публикации этот механизм автоматически не меняет.

## Проверено локально

- `tests/code-drafts.mts`: отдельные пространства аккаунтов/сайтов, строгий ограниченный формат, повреждённые/истёкшие/будущие записи, ошибка записи, безопасный вывод кода и отсутствие восстановления устаревшего черновика в EN/RU/ES.
- `tests/code-sections.mts`: изоляция своей секции кода.
- `tests/journey-http.mts`: гостевой первый результат и публикация, регистрация/подтверждение, AI и ручные правки, код, загрузка изображений, история, формы/уведомления, отчёты, резерв проекта, offline/republish, повторный вход и восстановление пароля. Отдельные временные данные, AI_DEMO, локальные письма.
- Через браузер: обычный вход в синтетический локальный аккаунт, ввод HTML/CSS, повторное открытие сайта в новой вкладке, явное восстановление точных значений, просмотр и применение в версию 2. Исходная вкладка создала ввод на базе версии 1: после обновления другой вкладки показано предупреждение об устаревании без кнопки восстановления. Выход и повторный вход удалили локальную копию.

При первой попытке локального HTTP-сервера песочница запретила listen. Повторный запуск разрешённого собственного тестового процесса прошёл; настройки системы не менялись. Локальные данные не являются аккаунтом владельца. Снимок: `data/verification/code-drafts-2026-11-03/local-stale.png`, вне git.

## Команды проверки

```sh
npm run build:webpack
node --import tsx tests/code-drafts.mts
node --import tsx tests/code-sections.mts
node --import tsx tests/journey-http.mts
npx tsc --noEmit
git diff --check
```

Для ручной проверки: открыть свой демо-сайт, вкладку «Код», ввести HTML без секретов. Повторно открыть этот сайт и выбрать «Код»: появится предложение восстановления. Восстановление не создаёт версию; нужны «Посмотреть изменения» и применение, затем отдельная публикация.
