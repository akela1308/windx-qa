# Этап E: проверка видимости в поиске

30 октября 2026. Реализован раздел E аудита. Этап F не начат.

## Результат

«3 проверки → Проверить видимость в поиске» и вкладка «Поиск» запускают техническую проверку без модели и AI-кредитов. Выбор: текущая сохранённая версия или именно опубликованная версия, даже если черновик уже изменён. Отчёт содержит дату, версию, источник, наблюдения, приоритет, уверенность, предложения и ссылки на правила. Доступны последние десять отчётов и отметка устаревания. Сводка также видна перед публикацией; новых блокировок публикации нет.

Проверяем title/description, число h1, язык страницы, canonical, внутренние якоря, контакты, неподтверждённые факты и базовую структуру LocalBusiness JSON-LD. Поддерживается 152 подтипа из официальной иерархии Schema.org. Один h1 является соглашением WINDX, а не обязательным условием индексации Google. Проверка языка эвристическая, проверка телефона не доказывает его существование. Полная применимость структурированных данных требует отдельной проверки.

Для публикации сервер запрашивает только три фиксированных адреса собственного сайта WINDX: `/`, `/robots.txt`, `/sitemap.xml`. Проверяются HTTP-статус, noindex в HTML/HTTP, базовые правила Googlebot/* для корня и ограниченная карта urlset. URL из HTML/XML не посещаются. Карты sitemapindex, другие адреса карт и сложные правила требуют ручной проверки. Отсутствие robots.txt, sitemap или canonical показано как возможное улучшение, а не запрет индексации. Эти файлы и разметка автоматически не создаются.

Источник «Публичный ответ HTTP» появляется только для полного ответа 200 text/html с совпавшими заголовками версии и момента публикации. Если это не подтверждено, анализируется сгенерированная копия выбранной версии и явно показывается неполнота сетевой проверки. Добавлены публичные заголовки `x-windx-version` и `x-windx-publication`; содержимое и кеширование страниц не менялись.

Три результата разделены: техническая готовность, индексация в Google, показы/переходы. Последние два остаются неизвестными: Search Console и аналитика не подключены. Позиции, трафик и попадание в AI-поиск не предполагаются. Проверка не гарантирует индексацию. Google может выбрать другое заглавие и описание.

Просьба о правке только заполняет чат. Модель не запускается, сайт и его публикация не меняются. Решения о реальных данных остаются владельцу, задачи уровня платформы обозначены отдельно. Проверка требований остаётся недоступной.

## Границы и защита

Проверяется основной HTML без выполнения своего JavaScript и вложенных embed. Общий изолированный рендер вынесен из проверки D в отдельный помощник: sandbox без scripts, CSP запрещает сеть, формы и фреймы. CSP ставится перед исходным HTML и действует также при необычном или отсутствующем head. XML с DOCTYPE/ENTITY отклоняется. Браузерное извлечение является данными браузера владельца, а не независимым серверным аудитом; на нём не строятся разрешения или решения о публикации.

Серверные сетевые наблюдения подписаны HMAC с привязкой к сайту, версии и цели на 10 минут. Секрет хранится локально с 0600. Подменённые, просроченные и устаревшие результаты отклоняются, повторная отправка того же запуска не создаёт дубликат. Действия проверяют владельца. Гостю доступна проверка своего пробного сайта до публикации, после публикации нужен аккаунт. Чужие отчёты недоступны, заявки не читаются.

История: `data/sites/<id>/checks/search`, файлы 0600, папки 0700, атомарная запись без перезаписи. Последние десять видны в интерфейсе, старые файлы автоматически не удаляются. Пределы: шесть стартов в минуту на сайт в процессе, 30 сохранений за час по файлам. Для нескольких экземпляров нужна общая блокировка; текущее размещение одноэкземплярное.

Сеть: таймаут 5 секунд на запрос, без редиректов и cookies, cache:no-store. Ограничения ответа: HTML 384 KB, robots 32 KB, sitemap 128 KB. Снимки браузера ограничены схемой. Для изолированных тестов `WINDX_SEARCH_HTTP=0` отключает HTTP и даёт честное состояние «не проверено».

## Проверено

- Production-сборка, `npx tsc --noEmit`, `npx eslint src`, `git diff --check` проходят.
- `search-check.mts`: метаданные, языки, noindex/группы robots, необязательные отсутствующие файлы, подтипы/контекст/поля LocalBusiness, подписи и срок, пределы HTTP, приватность, повторные и параллельные сохранения.
- `search-http.mts`: реальные production actions, разные сохранённая/опубликованная версии, подмена и устаревание, права гостя/владельца/чужого аккаунта, история, заголовки live, отсутствие изменений сайта/заявок и вызовов модели.
- Регрессии: works-check, works-http, enquiries, enquiries-http, auth-isolation, auth-http, guest-trial проходят.
- Браузер: локальный опубликованный Lowgear Cycle Works, версия 3, источник HTTP, `/` 200, robots/sitemap 404, пять задач для просмотра. Непубликованный works-probe проверен без HTTP. Метаданные раскрываются, недоступные данные Google обозначены явно. На ширине 390 px ширина документа 390 px. Скриншоты рядом в stage-e-proof.
- Изолированный браузерный тест реального модуля: извлечение метаданных, JSON-LD, якорей, XML; отсутствие выполнения скрипта и запрещённых запросов. Наблюдения сохранены в stage-e-proof/extraction.json.

Тесты используют временные данные и AI_DEMO. Клиентские сайты на production не изменялись, старый publication-test не публиковался заново. Проверка через аккаунт владельца на production и настоящий телефон в этой части не выполнялась: создание аккаунта ранее отложено. Локальные проверки не подтверждают индексацию Google.

Полные старые `npm run lint`/`npm run typecheck` включают прежние ошибки экспериментальных файлов; к этапу E они не относятся. Приведённые выше проверки src и production-сборка проходят.

## Команды

В актуальной копии проекта с установленными зависимостями:

```sh
npm ci
npm run build
node --import tsx tests/search-check.mts
node --import tsx tests/search-http.mts
```

HTTP-тест сам запускает production-сервер на 3200 и удаляет только свои временные данные. Для ручной проверки откройте свой сайт, вкладку «Поиск», выберите версию и нажмите «Запустить проверку».
