## Главные выводы

- Wix, Shopify и Lovable это три разных бизнеса. Wix живёт на подписках (83% маржа на них, ~$230 в год с платящего, 6,1 млн платящих из 304 млн зарегистрированных). Shopify зарабатывает 78% на обороте мерчантов (комиссии с платежей). Lovable продаёт кредиты на генерацию приложений, маржа ~35%, выручка с клиента падает после стройки.
- AI у всех встроен в старт (описал бизнес, получил черновик за 60-90 секунд). Ни у кого AI не доведён до надёжных действий после запуска сайта: советники работают в режиме «текст и чеклист». Wix верифицирует Search Console сам, Theo пишет статьи еженедельно, GBP через API делают только SEO-инструменты вне конструкторов.
- Lovable не «просто обёртка»: harness (оркестратор, eval-пайплайн, обратная связь из логов), песочницы на каждого, опинионированный стек, дистрибуция через комьюнити и бесплатный тир. Их слабости: плата за ошибки AI, одинаковый shadcn-дизайн, деградация при росте.
- 47% сайтов малого бизнеса получают ноль переходов из Google. Это второй, плохо закрытый спрос: не «сделать сайт», а «чтобы находили». В Британии 24-30% малого бизнеса без сайта, в США 27%.

## Позиционирование

«Сайт плюс присутствие в интернете на автопилоте» для локального сервисного бизнеса, одна ниша на старт. Три отличия:
1. Дизайн без слопа как система: вёрстку пишем мы (библиотека секций, 3-5 курируемых визуальных характеров на нишу, запрещённый список: Inter, фиолетовые градиенты, три карточки с иконками), AI заполняет JSON-данные, не пишет код. Дешевле ($0,15-0,5 за сайт), ничего не ломается, правки без LLM.
2. AI-советник, который делает: SEO на сайте, статьи по плану, AI-оптимизация (llms.txt, JSON-LD, FAQ), Google Search Console и Google Business Profile через API, еженедельный отчёт и три действия.
3. Внешнее присутствие по нише: база «ниша × страна × площадка» (общие: GBP, Apple Business Connect, Bing Places; нишевые агрегаторы записи; локальные каталоги: в Британии Yell, Thomson Local, Checkatrade, Trustpilot, в США Yelp, Nextdoor, BBB, Angi) с готовыми текстами и статусом размещения. Это наш актив.

Ниша НЕ выбрана (барбершоп в обсуждениях был только условным примером, Максим просил его не фиксировать). Критерии выбора: клиента ищут через поиск и карты, сайт влияет на доверие, есть понятная транзакция (запись, звонок, заявка), готовность платить, нет сильного вертикального игрока в Британии и США, до клиентов легко дотянуться в Лондоне. Ниша должна быть «пакетом» (секции, характеры, вопросы онбординга, площадки, темы статей), а не отдельным продуктом; первый набросок MVP делается на нейтральном пакете «локальный сервисный бизнес».

## Путь клиента (как описал Максим)

Регистрация → промпт о бизнесе (+ фото/Instagram) → базовый сайт за минуту → улучшения (фирменный элемент как апселл, смена характера) → SEO на сайте и план статей → площадки по нише → поддомен бесплатно или домен через партнёра → публикация с хостингом и AI-оптимизацией → ежемесячная подписка за поддержание и продвижение. Точки оплаты: токены, фирменный элемент, домен, подписка. Первый черновик лучше отдавать бесплатно.

## План

- Фаза 0 (2 недели, без кода): выбрать нишу, собрать для неё пакет и базу площадок для Лондона, 5 сайтов вручную, 10 разговоров о цене. Если меньше трёх из десяти готовы на £25+, меняем нишу.
- Фаза 1 (4-6 недель): регистрация, онбординг, генерация в JSON, редактор без LLM (Puck), поддомены, базовое SEO и llms.txt, Search Console, список площадок, оплата.
- Фаза 2 (4 недели): статьи, GBP через API, еженедельный отчёт, фирменные элементы, домены через реселлерский API, бейдж на бесплатных сайтах.
- Фаза 3: второй нишевой пакет, выход на США (Yelp, Nextdoor, цены в долларах), партнёрка для студий, дальше Европа.
- Не делаем в MVP: свободную генерацию кода, свой магазин и запись, свободный drag-and-drop, маркетплейс приложений, мультиязычность, мобильное приложение.

## Архитектура и инфраструктура

Next.js + Tailwind (multi-tenant, один деплой на все сайты), сайт как JSON-дерево секций (схема на zod), редактор Puck (MIT), Claude Sonnet для генерации и текстов + Haiku для мелочей (только JSON-схема через tool use), Supabase, хостинг Vercel (wildcard-домен, безлимит кастомных доменов на Pro $20/мес) или Cloudflare (100 кастомных доменов бесплатно, далее $0,10), домены через реселлерский API (Openprovider, Namecheap, Name.com; опт .com ~$10-11, продаём $18-22), оплата Stripe (фунты и доллары с одного аккаунта) или Paddle/Lemon Squeezy как merchant of record для VAT и sales tax. Постоянные расходы на инфраструктуру для первых 500 сайтов: $50-100 в месяц.

## Финансовая модель (предложение для проверки)

Цифры в евро для простоты; для Британии те же числа в фунтах, для США в долларах. Бесплатно: черновик с бейджем. Токены €9/100, €19/250. Сайт €12/мес. Сайт + продвижение €29/мес (основной: 2-4 статьи, GBP-посты, площадки, отчёт). Про €59-79. Домен €18-22/год. Себестоимость основного тарифа €2-4, маржа ~85%. При оттоке 5% LTV ~€580, допустимый CAC €100-150. 100 клиентов = ~€2 900 MRR. Первый порог: 100 платящих в одной нише в Лондоне за 3-4 месяца.

## Риски и открытые вопросы

GBP API и OAuth-проверка Google занимают недели (подать сразу); верификация профиля остаётся на владельце. Гиганты могут повторить. Статьи рискуют быть слопом (мало, локально, с фактами клиента, одобрение владельцем). Дизайн-система без дизайнера даст зафиксированный слоп.

Решить до фазы 1: ниша, Лондон целиком или один-два района, кто делает библиотеку секций, токены + подписка или только подписка, экспорт HTML да/нет, название продукта (WINDX?).
