## Найдено и исправлено

1. Во время подготовки ручной правки поля изображения оставались активны, хотя остальные поля были заблокированы. Теперь описание, кадрирование, удаление и повторная загрузка также блокируются до завершения действия. Для передачи файла и подготовки просмотра используются разные подписи; это дополнительно проверяется компонентным тестом.
2. Сборка с `--webpack` не включала Tailwind, поскольку прежняя настройка обрабатывала CSS только в Turbopack. Это делало локальную визуальную проверку недостоверной. Подключение переведено на [официальную схему Next.js и Tailwind через PostCSS](https://tailwindcss.com/docs/installation/framework-guides/nextjs), с тем же Tailwind 4.3.3. Добавлены проверка готового CSS и команда `npm run build:webpack`. Обычная сборка также проверяет наличие стилей после компиляции. Версии Next/React и правила дизайна не менялись.
3. Тест удаления метаданных прежде использовал вход без EXIF. Теперь он сначала доказывает наличие метки во входном файле и затем её отсутствие в результате.

Первоначальная неудача выбора файла во встроенном браузере оказалась ограничением способа управления скрытым input. Выбор через сам input и клавиатуру успешно открыл штатный выбор файла. Ослабление безопасности браузера или смена настроек компьютера не потребовались.
