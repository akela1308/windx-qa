# Свой код: первый шаг свободного редактора

29 октября 2026 года. По поручению владельца реализована секция своего HTML, CSS и JavaScript. Полноценный «зеро-блок» остаётся следующим отдельным этапом. Форма заявки в эту работу не входит.

## Что работает

- Вкладка Code в кабинете: добавление секции в выбранное место, изменение и удаление.
- Отдельные поля HTML, CSS и JavaScript, название для доступности, высота для компьютера и телефона.
- Предпросмотр и список изменений до применения. Отказ сохраняет текущую страницу. Применение создаёт версию черновика, публикация остаётся отдельным действием.
- Восстановление через историю, выбор секции прямо на превью. Добавление секции не показывает соседние неизменённые разделы как отредактированные.
- Ручная операция не вызывает модель, не расходует AI-кредиты и не создаёт запись AI-запроса.
- AI получает обозначение секции без исходников. Проверка ответа запрещает ему создавать, удалять или менять собственный код клиента, включая запросы на полный редизайн.

Требование свободного визуального редактора и последовательность работы записаны в мастер-контексте и [описании следующего этапа](free-editor-and-code.md). Существующая библиотека композиций не объявлена окончательной архитектурой.

## Изоляция и ограничения

Секция выполняется в iframe с `sandbox="allow-scripts"`, без `allow-same-origin`. Это позволяет выполнять JavaScript, сохраняя отдельный непрозрачный origin, как определено в [стандарте HTML](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox). У секции собственные стили, она не управляет разметкой кабинета. Сообщения от вложенного кода не принимаются инструментом выделения разделов.

Доступны внешние ресурсы по HTTPS. CSP запрещает объекты, базовый URL и отправку форм; iframe не получает разрешения на всплывающие окна, верхнюю навигацию, камеру, микрофон, геолокацию и платежи. Это ограниченный вариант вставки: виджеты, которым нужны cookies, доступ к родительскому DOM или другие разрешения, могут не работать. Универсальная совместимость с внешними виджетами не проверялась. Код виден посетителям; ключи и другие секреты в него помещать нельзя. Изоляция не запрещает самому коду обращаться к внешним HTTPS-сервисам, о чём интерфейс предупреждает до просмотра.

Размеры источников ограничены: HTML 50 000, CSS и JavaScript по 30 000 символов. Высота 120–2000 px, для узкого экрана отдельное значение. Автоматическая высота и визуальное перетаскивание элементов в эту часть не входят.

Регрессии этапа C и инструкции качества дизайна также проходят.

## Ручная проверка

Запустить кабинет с отдельным хранилищем, чтобы не менять рабочие данные:

```sh
AI_DEMO=1 WINDX_DATA_DIR=/tmp/windx-code-manual npm run dev -- --hostname 127.0.0.1 --port 3180
```

Открыть `http://127.0.0.1:3180`, создать демо-сайт, открыть Code и добавить HTML `<button id="count">Count: 0</button>`. В JavaScript вставить:

```js
let count = 0;
document.getElementById('count').onclick = (event) => {
  event.currentTarget.textContent = `Count: ${++count}`;
};
```

Задать разную высоту для компьютера и телефона. Просмотреть предложение, нажать счётчик, применить, проверить оба размера. Изменить секцию и отклонить предложение; затем удалить и вернуть через историю. Публикацию выполнять отдельно только для намеренно выбранного сайта.
