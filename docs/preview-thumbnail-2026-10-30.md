# Полоса прокрутки в миниатюрах сайтов

30 октября 2026 года. Пользователь заметил, что карточки показывают полосу прокрутки, хотя прокрутить вложенный сайт нельзя.

Причина: `SiteCard` показывает уменьшенный iframe с `pointer-events: none`. Браузер рисовал в нём обычную полосу прокрутки длинной страницы, создавая ложное ожидание взаимодействия.

Исправлено только поведение миниатюр:

- Карточка запрашивает версию страницы с `?thumbnail=1`. Для этого режима корневые элементы получают `overflow: hidden` и скрытие полос браузера.
- Полное превью и режим редактора сохраняют обычную прокрутку.
- Нажатие по миниатюре открывает редактор. Ссылка получила доступное название с именем сайта; декоративный iframe скрыт от экранного диктора и исключён из порядка Tab.

Проверено в локальном кабинете с демо-данными: миниатюра длинной страницы имеет `overflow: hidden`, `scrollbar-width: none`, нажатие открывает редактор. В редакторе остаются `overflow: visible` и `scrollbar-width: auto`, высота страницы превышает высоту окна превью. Проверки TypeScript, ESLint изменённых файлов и `git diff --check` проходят. Новые платные запросы не выполнялись. Публичная версия после изменения не проверялась.

Команды:

```sh
npx tsc --noEmit
npx eslint src/components/home/SiteCard.tsx 'src/app/preview/[id]/[n]/route.ts'
git diff --check
```

Ручная проверка: открыть «Мои сайты», убедиться в отсутствии внутренней полосы у миниатюры, нажать на неё и прокрутить сайт уже в редакторе.

## Удаление карточки New site

По следующей просьбе владельца карточка с плюсом удалена из общей сетки сайтов. При пустом списке остаётся текстовое объяснение. Создание доступно через существующее меню. Проверено в локальном браузере; TypeScript и ESLint `SitesGrid.tsx` проходят.
