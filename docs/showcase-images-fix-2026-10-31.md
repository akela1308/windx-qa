# Восстановление картинок главной

Дата: 31 октября 2026 года.

На рабочей главной исчезли три снимка сайтов: newsprint, soft-clay и signal. Исходные JPEG оставались на месте и отвечали HTTP 200, но запрос `/_next/image?url=%2Fshowcase%2Fnewsprint.jpg&w=640&q=75` возвращал 404 с сообщением об ошибке внутреннего ответа.

Причина: Next.js 16.4.3 в `fetchInternalImage` читает локальный исходник внутренним запросом с пустыми заголовками. Добавленная в этапе G проверка неизвестного Host отклоняла такой запрос. Это затрагивало также другие картинки витрины и значок Google.

В proxy добавлено узкое исключение для существующих публичных изображений: `/showcase/<имя>.jpg` с буквами, цифрами и дефисами в имени, а также `/brands/google-g.png`. Остальные маршруты проходят прежние проверки домена и доступа. Компоненты главной, исходные изображения и композиция не менялись.

Регрессионная проверка в `tests/domains-http.mts` сначала воспроизвела 404 на старой production-сборке. На исправленной сборке проверены оптимизированные ответы для всех десяти showcase-снимков, включая редактор, и значка Google. Каждый ответ имеет статус 200, тип image и непустое тело. Отдельно проверено, что оптимизатор не отдаёт приватные страницы. Прежние проверки доменов, владельцев, публикации и форм также прошли.

Проверки:

```sh
npm run build &&
node --import tsx tests/domains-http.mts
```

`npx eslint src/proxy.ts` также прошёл.

Английский заголовок не менялся. Владелец выбрал русский заголовок «Мы генерируем, но иначе»; изменено только поле `home.title` русского перевода.

Отдельная успешная проверка создания и публикации: [отчёт](subdomain-live-check-2026-10-31.md).
