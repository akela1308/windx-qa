Classes

Slow flow

Linked movement at a pace where you can feel each shape. Breath leads, the sequence follows. Good if you have practised before and want to stay close to the floor.

Yin

Few poses, held for a long time, mostly lying or sitting. Quiet and heavy in the best way. Nothing to get right.

Beginners course

Four weeks, the same small group each week. We learn the basic shapes and how to breathe through them, so that you can walk into any class afterwards.

4 weeks

Pregnancy yoga

Saturday mornings. Gentle movement, breathing and rest for pregnant women, in a room that has space for everyone.

Before your first class

I have never done yoga. Will I be the only one?

There are only 14 mats, so nobody disappears at the back. Tell Mei or the teacher on the day and they will keep an eye on you. The 4 week course is there if you would rather start with others who are new.

What do I bring?

Something comfortable to move in. The floor is wooden and the room is warm, so you will not need layers. We have a few spare mats if you do not own one.

Which class should I book?

If you want to move, slow flow. If you want to stop, yin. If you are pregnant, Saturday mornings. If you are unsure, send a message and Mei will answer.
