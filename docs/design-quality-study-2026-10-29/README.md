# Проверка рабочих принципов дизайна

29 октября 2026 года. [Открыть сравнение](index.html). Кнопка «Телефон 390 px» задаёт ширину вложенных страниц; варианты можно открыть отдельно. Для просмотра без локального сервера открыть `index.html` в браузере.

## Что сравнивается

Основа: светлые примеры мастерской, юридической практики и йоги из эксперимента 1c. Варианты подготовлены Codex в сессии из тех же документов. Это контролируемый разбор композиций, без вызова платного API, новой независимой генерации и слепой оценки.

Скрипт проверяет неизменность содержательных разделов, метаданных и списка фактов. Декоративные разделы с их текстами и подписями могут отличаться; все удалённые элементы полностью записаны в `checks.json`. Поэтому это не сравнение побуквенно одинакового текста всей страницы. Единственная замена ссылки: пункт The room у йоги теперь ведёт к главному экрану с описанием комнаты вместо удалённого плана.

| Пример | Изменение | Вывод для рабочего процесса |
| --- | --- | --- |
| Мастерская | Контрольная пара без изменений, сохранены рисунок арки, крупная цена и выделенная фраза | Принципы не требуют делать все сайты тихими. Выразительные решения могут соответствовать содержанию. |
| Юридическая практика | Убраны гигантские 20 min, рисунок двери и выделенная фраза; основной текст заменён на Public Sans, масштаб заголовков стал modest | Услуги, бесплатный звонок и контакты остаются понятными без трёх отдельных акцентов. Информация о 20 минутах сохраняется в содержательных разделах. |
| Йога | Убраны повторная плашка о 14 ковриках и вымышленный план комнаты; записка преподавателя сохранена | Тёплый характер может держаться на наборе, палитре и личном голосе. Точный план помещения нельзя придумывать по количеству ковриков. |

Это оценка автора вариантов, не результат голосования посетителей. Сокращение высоты страницы само по себе не означает улучшение конверсии. Фотографии в обоих вариантах обозначены местами для будущих материалов владельца. Старые демонстрационные адреса, расписания и ссылки не подтверждены для реального бизнеса; страницы не публиковались.

## Проверка в браузере

Chrome, ширина 1280 и 390 пикселей: у всех шести страниц ширина документа совпадает с шириной экрана, потерянных якорей меню не обнаружено. Полные широкие снимки и первые экраны мобильных вариантов сохранены рядом. Размеры страниц и состояние шрифтов записаны в `browser-checks.json`.

Просмотр показал ограничение библиотеки: длинный заголовок юридического примера на телефоне получается слишком мелким и в исходном, и в новом варианте. У мастерской длинный email переносится внутри слова. Это задачи следующей проверки композиций, не доказательство готовности этих страниц к коммерческой публикации. В этой работе код композиций не менялся.

## Что изменено в рабочей генерации

Короткая инструкция `src/lib/prompts/design-quality.md` подключена сборщиком системного промпта. Отменены автоматические требования двух выразительных элементов, обязательного SVG, максимума двух вступлений и запрет FAQ непосредственно перед контактами. Схема, проверки контраста и текстовых оборотов сохранены. При узкой правке сохраняются область запроса и предварительный обзор этапа C.

Причина изменения: прежние проверки отклоняли спокойную страницу из-за отсутствия украшений независимо от её содержимого. Это проверено отдельным тестом. Композиционные рекомендации перенесены в промпт и визуальную рубрику; автоматический детектор художественного качества не заявляется. Изменение относится к будущим запросам, уже сохранённые сайты автоматически не переделываются.

## Воспроизведение

Из корня проекта:

```bash
node --import tsx experiments/exp1c/build-prompts.ts
node --import tsx experiments/design-quality/run.mts
node --import tsx --test tests/design-quality.mts tests/stage-c.mts
npx tsc --noEmit
```

Для локального просмотра:

```bash
python3 -m http.server 3174 --bind 127.0.0.1 --directory docs/design-quality-study-2026-10-29
```

Открыть `http://127.0.0.1:3174/`. Скрипт воспроизводит JSON, HTML и проверки содержимого. Снимки браузера и `browser-checks.json` относятся к ручной проверке через инструменты браузера и этим скриптом не обновляются.

Проверки выполнены: пять групп тестов, TypeScript приложения, ESLint изменённых файлов и production-сборка прошли. Автоматические проверки содержимого прошли для всех трёх пар. На опубликованном сервере новые правила ещё не проверялись; платная модель не вызывалась.

Следующая оценка: новые генерации по одинаковым заданиям и просмотр владельцем, затем сравнение по рабочей рубрике. Переход к форме заявки этапа C в эту работу не входит.
