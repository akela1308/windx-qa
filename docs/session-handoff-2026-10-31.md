## Решения владельца которые сохраняем

- WINDX создаёт сайты по описанию и позволяет дорабатывать их просьбами к AI. Первый рынок: Британия и Лондон; ниша пока не выбрана.
- Создание и первая публикация доступны без регистрации. Для последующих правок и управления нужен аккаунт. Пробный сайт должен перейти в него с сохранением адреса и версий.
- Сайты разных пользователей изолированы. Общий список всех сайтов нельзя возвращать ни в интерфейс, ни через прямые действия или превью.
- Публикация отдельна от сохранения правки. В интернете остаётся опубликованная версия, пока владелец явно не опубликует изменения.
- Придуманные AI сведения требуют подтверждения. На опубликованном сайте нет обязательного значка WINDX.
- Узкая просьба меняет только затронутую область. Фактические изменения показываются до применения; общие рекомендации дизайна не оправдывают перестановку соседних разделов.
- Качество и разнообразие дизайна важны. Одинаковая сетка карточек не является подачей по умолчанию. Полный свободный редактор не заменяется библиотекой композиций.
- Новые платные сервисы без согласования не подключаем. Разрешены существующие Railway и OpenRouter. Дорогие действия и рост постоянных расходов требуют предварительной оценки; точные тарифы ещё не утверждены.
- Техническая проверка поиска не обещает индексацию, а проверка требований не подтверждает юридическое соответствие.

## Последние исправления интерфейса

- Три картинки первого экрана восстановлены. Исходники не исчезали: проверка Host блокировала внутренние запросы оптимизатора Next.js без этого заголовка. В proxy добавлено узкое исключение только для публичных showcase JPEG и значка Google. Проверены все снимки витрины и недоступность приватных страниц через оптимизатор. [Отчёт](showcase-images-fix-2026-10-31.md).
- Русский заголовок выбран владельцем: **«Мы генерируем, но иначе»**. Вариант «Создай, но не так как у всех» обсуждался, но не установлен. Английский сохранён: **“A website that looks designed, not generated.”**
- Из формы убран второй выбор языка рядом с микрофоном. При смене языка кабинета текущая диктовка завершается с сохранением распознанного текста. Следующий запуск использует `ru-RU`, `en-GB` или `es-ES` по интерфейсу. Запись с настоящего микрофона при этой последней правке не проверялась.
- У статических миниатюр сайтов скрыта ложная полоса прокрутки. Полноценное превью продолжает прокручиваться. Пустая карточка New site из списка сайтов удалена. [Отчёт](preview-thumbnail-2026-10-30.md).
- Исправлены стрелки и отступы выбора языка и сортировки. Узкая AI-правка умеет убирать декоративное подчёркивание через `mark: none`, сохраняя слова.
- Русская просьба владельца должна получать русский ответ AI, при этом язык английского клиентского сайта сохраняется. Для ответов-правок уточнён JSON-формат; некорректный ответ не должен менять сайт.

```sh
# Доступ и пробный сайт
node --import tsx tests/auth-isolation.mts
node --import tsx tests/guest-trial.mts
node --import tsx tests/auth-http.mts

# Формы
node --import tsx tests/enquiries.mts
node --import tsx tests/enquiries-http.mts

# Три проверки
node --import tsx tests/works-check.mts
node --import tsx tests/works-http.mts
node --import tsx tests/search-check.mts
node --import tsx tests/search-http.mts
node --import tsx tests/requirements-check.mts
node --import tsx tests/requirements-http.mts

# Домены и публичные картинки
node --import tsx tests/domains.mts
node --import tsx tests/domains-network.mts
node --import tsx tests/domains-http.mts

# Диктовка
node --import tsx tests/voice.mts
```

HTTP-тесты требуют предварительной production-сборки, поднимают собственные локальные серверы и удаляют свои временные данные. Не останавливать чужой процесс ради занятого тестового порта. Эти команды перечислены для повторения, не как заявление о новом полном прогоне при создании сводки.

Общий `npm run typecheck` включает старые эксперименты с прежними ошибками и абсолютными путями. Он отличается от `npx tsc --noEmit`, проверяющего приложение. Не объявлять известные ошибки старых экспериментов новым дефектом этой сессии и не переписывать их без поручения.

## С чего продолжить

Свой домен и Google-настройку сейчас не возобновлять. Перед крупным новым этапом выбрать задачу с владельцем. Предлагаемый порядок:

1. Уточнить активацию личного аккаунта и доступ к своим сайтам, без передачи паролей агенту.
2. Пройти в аккаунте единый пользовательский цикл на демонстрационных данных: правка с просмотром, публикация, заявка, ящик и отчёты трёх проверок. Проверять сохранность версий и разделение данных.
3. Выбрать следующий самостоятельный этап: восстановление/подтверждение аккаунта, предварительная стоимость, интеграция свободного редактора или сопровождение. Это предложение порядка, не уже утверждённый новый план.
4. Когда владелец вернётся к внешнему домену, использовать отдельный поддомен принадлежащего ему адреса. До изменения DNS посмотреть текущие записи; не менять основной сайт, MX или серверы имён ради теста.
