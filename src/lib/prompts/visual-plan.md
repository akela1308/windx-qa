## Visual plan contract

Every newly created site includes visualPlan, written in the cabinet language. It is private design guidance, not page copy. Its intent states the visitor's main task. Its layout explains the chosen opening, the text/visual relationship and the next useful section. references lists only IDs supplied in this request that actually influenced a decision; an empty list is valid.

For each image or vector illustration actually used, give its section a unique id and add an images entry with that sectionId. State its role (person, place, product, work, explanation or atmosphere), subject, purpose, framing (portrait, landscape, square or wide), placement relative to the copy and mobile order, and the focalPoint to preserve when cropping. source=owner means a supplied image with an exact src from the inventory. source=original-vector means an original vector actually rendered in that section. A logo may be described as atmosphere. Use the current inventory, not an assumption that every brief has no photographs.

When an extra real image would materially help later, source=optional-owner can describe it against an existing section id. The initial page must already work without it; do not render an empty frame, a photo description or an upload instruction. Optional enrichment is not a task the owner must complete. Do not prescribe pictures merely because the schema contains image fields. An empty images list is valid for a page whose content is served by type alone.

There is no photograph URL generation. Use only the exact src values supplied by the server in Available owner image inventory. A syntactically valid invented /media/ path is still invalid. Do not reuse award previews. Do not depict a fictional room, team, product result or client project as real evidence. The private plan never substitutes for an actual image on the page.

When a meaningful image is available, choose its spatial role before its frame. hero.image-led groups a compact title with explanation/action above a wide image; hero.portrait-intro introduces a person with a narrow portrait and a readable text column. Existing full-photo, offset-photo, split-photo and gallery compositions are alternatives when the material and visitor task support them. These examples are not a ranking, industry lookup or required layout. Without an appropriate image, use the available text and vector compositions and keep optional photography in the private plan. Avoid the universal giant name plus facts row and ticker seen in the old speaker example unless that particular brief makes it useful.
