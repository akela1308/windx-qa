# Один выбор языка для интерфейса и диктовки

Дата: 31 октября 2026 года.

По просьбе владельца отдельный выбор языка рядом с микрофоном убран. Единственным выбором остаётся язык кабинета в боковом меню. Каждый запуск распознавания получает текущий `t.lang`: русский интерфейс использует `ru-RU`, английский `en-GB`, испанский `es-ES`.

При смене языка интерфейса текущая сессия диктовки завершается. Уже распознанный текст сохраняется, следующий запуск использует новый язык. Это выбор языка через интерфейс, не автоматическое определение языка по голосу.

Микрофон, остановка, обработка ошибок и объяснение работы браузерного распознавания сохранены. При открытии страницы доступ к микрофону по-прежнему не запрашивается.

Проверки:

```sh
npm run build &&
node --import tsx tests/voice.mts
```

Проверка ESLint компонента также прошла. Настоящая запись с микрофона в этой правке не выполнялась.
