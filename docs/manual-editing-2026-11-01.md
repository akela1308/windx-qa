# Ручное редактирование текста и своих изображений

1 ноября 2026 года. Реализация завершена, проверена локально и выложена штатным CI. Подтверждение выкладки и границы живой проверки: [итог замечаний](owner-remarks-2026-11-01.md#выкладка).

## Путь клиента

После входа открыть сайт и вкладку «Текст и изображения». Раздел выбирается в списке либо кнопкой над предпросмотром и кликом по блоку. Изменить текст, подписи кнопок и адреса ссылок, заменить фото, загрузить логотип. Заголовок и описание страницы находятся отдельным пунктом списка. Просмотр изменений не меняет сайт; применение создаёт новую версию черновика без AI-вызова и расхода кредитов. Публикация остаётся отдельной кнопкой. История восстанавливает прежнюю версию.

Фото можно заменить в существующем месте либо добавить отдельным разделом перед подвалом. Поддерживаются альтернативный текст, заполнение рамки или показ целиком, горизонтальный и вертикальный фокус. Это кадрирование при отображении, исходное изображение не режется при каждом перемещении фокуса. Логотип показывается целиком рядом с названием бизнеса, поддерживаются все три шапки и оба подвала.

Это редактор полей существующих разделов. Свободное размещение элементов, слои, шрифты, добавление/удаление строк списков и интеграция прототипа zero-block сюда не входят. Свой HTML/CSS/JS редактируется отдельной вкладкой.

## Сохранность и доступ

- Изменяется выбранный раздел или метаданные. Вставка фото не показывает неизменённый подвал как переписанный.
- Применение устаревшего предложения отклоняется. Текст при ошибке остаётся в форме. Смена раздела, вкладки и уход к списку сайтов предупреждают о несохранённом вводе.
- Принимаются JPG, PNG и WebP до 8 МБ; проверяется реальное содержимое. Изображения повторно кодируются в WebP с нормализацией ориентации, без переноса EXIF/GPS, уменьшаются до 2400 px. Максимум 20 млн входных пикселей. SVG, анимация и HEIC не поддерживаются.
- Файлы хранятся на существующем диске WINDX внутри каталога сайта. Новый платный сервис не подключался.
- Загрузка разрешена только зарегистрированному владельцу, с проверкой Origin и ограничением размера потока. Чужой файл нельзя подставить по адресу в документ другого сайта.
- Черновые файлы доступны владельцу. Посетитель получает только файлы, используемые опубликованной версией. После Take offline публичный доступ закрывается, ответы изображений не кешируются. Уже скачанные пользователем байты отозвать невозможно.
- Копирование сайта создаёт независимые копии используемых изображений. Удаление оригинала не ломает копию. Удаление сайта удаляет его каталог с файлами.
- Старые файлы сохраняются для истории. Временный технический предел: 100 загрузок и 80 МБ на сайт, включая отклонённые загрузки. Отдельного управления медиатекой и очистки неиспользуемых загрузок пока нет; это не утверждённый коммерческий тариф.
- AI получает существующие ссылки на фото, промпт требует их сохранять. Валидатор запрещает модели придумывать новые ссылки на загруженные изображения.

Дополнение по замечаниям: из списка фактов можно перейти к редактированию раздела. При реальной ручной правке владелец явно выбирает, какое неподтверждённое сведение заменил или удалил. Снятие старого пункта видно в просмотре изменений и сохраняется в новой версии, остальные факты автоматически не подтверждаются. Подробности: [замечания владельца](owner-remarks-2026-11-01.md).

## Проверка

Прошли штатная production-сборка Next.js с Turbopack, TypeScript и eslint приложения. Новые тесты:

```sh
npm ci
npm run build
npx tsc --noEmit
npx eslint src
node --import tsx tests/content.mts
node --import tsx tests/content-http.mts
node --import tsx tests/content-browser.mts
```

HTTP-тест запускает отдельный сервер на 3213: доступ разных аккаунтов, Origin, ограничения формата и размера, приватность файлов, узкие изменения, неверные пути/ссылки/чужие фото, просмотр/отклонение/применение, разделение черновика и публикации, поддомен с настоящим Host, метаданные, отдельная вставка фото, устаревшее предложение, возврат версии, копирование, снятие/повторная публикация и удаление. Данные изолированы во временном каталоге.

Браузерный тест на 3214 прошёл на русском UI: изменение заголовка, отмена смены вкладки и ухода из редактора, загрузка, alt, кадрирование, просмотр и применение, сохранение после reload, дополнительное фото, ширина 390 px, отсутствие ошибок JavaScript. Это локальный Chromium, не проверка настоящего телефона. Снимки: `data/verification/manual-editor-desktop-2026-10-31.png` и `manual-editor-mobile-2026-10-31.png`; имена сохранены для совместимости скрипта.

Дополнительно прошли прежние проверки D/E/F и domains-http. Реальный внешний домен не подключался. npm audit показывает 17 moderate предупреждений цепочки ESLint/minimatch, без high/critical, не в sharp; несвязанные автоматические обновления не выполнялись.
