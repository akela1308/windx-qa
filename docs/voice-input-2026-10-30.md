# Голосовой ввод описания сайта

30 октября 2026. Отдельная просьба владельца после этапа E. Этап F не начат.

На главной, в форме создания сайта, добавлена кнопка с микрофоном «Надиктовать». Языки: русский, английский, испанский. Исходный язык соответствует интерфейсу, язык диктовки можно выбрать отдельно. `/new` ведёт на ту же форму.

Диктовка дописывает окончательно распознанные фразы к существующему тексту. Промежуточная фраза показана отдельно и не отправляется в создание сайта. Пока идёт запуск/диктовка/завершение, поле доступно для чтения, выбор примеров, языка и создание сайта заблокированы. После остановки текст можно исправить обычным способом. Автоматического создания сайта нет.

Использован браузерный Web Speech API (SpeechRecognition/webkitSpeechRecognition), без нового платного сервиса, ключей и API-маршрута WINDX для аудио. WINDX не хранит аудио. Браузер может отправлять речь своему сервису распознавания; это объяснено рядом с кнопкой. При загрузке страницы доступа к микрофону нет, start вызывается только по нажатию. Требуется безопасный контекст, на production HTTPS.

Поддержка зависит от браузера, устройства и сервиса распознавания. Наличие API не гарантирует работающий сервис, в том числе в некоторых браузерах на Chromium. Для отсутствующего API, отказа в разрешении, отсутствия микрофона, сетевого сбоя и неподдерживаемого языка есть понятные сообщения и возможность продолжить текстом/диктовкой клавиатуры устройства. Обещания работы в каждом браузере или офлайн нет. Универсальный серверный распознаватель не подключён.

Одна сессия без автоматических перезапусков. Ожидание запуска ограничено 20 секундами, диктовка двумя минутами, завершение четырьмя секундами. Уход со страницы/скрытие вкладки прекращает распознавание. Уже окончательно распознанный текст сохраняется, промежуточный не выдаётся за окончательный. Обработчики и таймеры очищаются, поздние события не меняют поле.

## Проверка

- Production-сборка, TypeScript и eslint src проходят.
- `node --import tsx tests/voice.mts`: язык, промежуточный/окончательный результат, отсутствие дублей, поздняя окончательная фраза после stop, отмена запуска, отказ в доступе, очистка, исключение start, сохранение набранного текста.
- В браузере протестирован настоящий компонент с имитацией распознавателя на отдельном временном localhost: русский и английский результаты, выбор языка, блокировка отправки, промежуточная фраза, восстановление после отказа в доступе. Настоящий микрофон владельца не использовался, точность распознавания реального звука не проверена.
- Главная проверена на 1280px и 390px, документ на мобильной ширине не шире экрана. Скриншоты: voice-proof/desktop.png и mobile.png.

Ручная проверка на HTTPS: выбрать язык, нажать «Надиктовать», разрешить микрофон, произнести описание, нажать «Остановить», поправить текст. Проверить русский и английский, повторный запуск, отказ в разрешении. Только после проверки текста нажимать «Создать сайт».

Источники, сверены 30.10.2026: [Web Speech API](https://webaudio.github.io/web-speech-api/), [SpeechRecognition и ограничения браузеров](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).
