## Состояние

Изменения находятся в рабочем дереве основного проекта, ещё НЕ закоммичены, НЕ отправлены и НЕ развёрнуты. В main последний коммит до этой работы: 8bf9eb5. Пользовательскую папку Research/ не трогать и не добавлять в коммит.

Реализовано:

- Вкладка «Текст и изображения» для владельца аккаунта, выбор секции в списке или через существующий выбор блока в превью. Это редактирование полей, не contenteditable и не интеграция свободного редактора.
- Текст, подписи кнопок, ссылки, заголовок и описание страницы. Поля извлекаются из действующей схемы композиций; технические SVG и настройки оформления исключены.
- Предложение изменений, отклонение/применение, новая версия черновика, история; публикация отдельно. Есть предупреждение о потере несохранённого ввода.
- POST /sites/[id]/images: аккаунт/владение, Origin, ограничение потока 8 МБ, JPEG/PNG/WebP. Sharp 0.35.5 добавлен как явная зависимость (раньше транзитивная зависимость Next).
- Перекодирование в WebP, нормализация ориентации, максимум 20 млн входных пикселей, уменьшение до 2400 px. SVG и анимация не поддерживаются.
- Фото в существующих слотах, альтернативный текст, заполнение/показ целиком, фокус кадра. Логотипы во всех трёх шапках и двух подвалах.
- Новая композиция media.image и вариант «Добавить изображение перед подвалом», чтобы загрузка была полезна и на сайте без существующих фото-слотов.
- GET /media/[siteId]/[file]: черновые изображения доступны владельцу, публично только изображения опубликованной версии. No-store. Маршруты поддоменов и собственного домена расширены только для этих изображений, проверка привязки сохраняется.
- Копирование сайта копирует изображения, файлы находятся внутри каталога сайта и удаляются с ним. Старые изображения сохраняются для версий; временная квота 100 файлов / 80 МБ на сайт, включая неприменённые загрузки. Это технический предел, не утверждённый тариф.
- Промпт просит AI сохранять изображения; проверка AI-правок запрещает придумывать новые /media/ URL.

## Продолжить после команды владельца

1. Прочитать AGENTS.md, CLAUDE.md, мастер-контекст и этот файл. Сначала проверить git status, не потерять рабочие изменения. Не запускать git pull поверх них без проверки состояния.
2. Повторить браузерный тест и исправить реальные найденные проблемы, не ограничиваться обходом селекторов. Проверить загрузку, подпись/кадрирование, просмотр/применение, сохранение после reload, отдельную вставку фото, телефон и ошибки консоли. Тест поднимает собственный сервер 3214 и удаляет своё временное хранилище. HTTP-тест использует 3213. После выполнения предыдущие тестовые серверы остановлены в finally.
3. Улучшить отчёт новой вставки media.image: сейчас общий describeChanges сравнивает секции по индексам и может показать сдвинутый подвал как изменение. Для кода и форм уже есть describeManualChanges в src/lib/sites/edit-review.ts. Использовать аналогичное сравнение для добавления фото, а на странице редактора выбирать его и для сохранённого pending manual. Не скрывать реальные изменения текста.
4. Проверить обозначение media.image в списке/просмотре: placeOf пока не знает media и выдаёт «другое». Дать понятное имя «Изображение» без изменения других мест.
5. Проверить сценарии несохранённого ввода при выборе блока/смене вкладок/уходе; при загрузке другой блок не должен терять незавершённый результат. Подтверждение фактов остаётся прежним: ручная правка пока не пересобирает текст списка factsToConfirm, оценить UX и явно зафиксировать границы.
6. Добавить проверку отдельного фото и метаданных в HTTP-тест, если браузер не покрывает нужные серверные ограничения; проверить фото в разных композициях, историю и публикацию после изменения. Итоговые build/tsc/eslint/diff-check.
7. Завершить документацию этапа и актуализировать продуктовый отчёт для партнёра: не называть текущую функцию полноценным свободным редактором. Мастер-контекст без отдельной просьбы не менять.
8. Только после завершения и проверок коммитить явным списком файлов, push main по действующим правилам проекта и наблюдать CI/конкретную выкладку Railway. Не запускать второй ручной deploy. Сегодня по просьбе владельца commit/push/deploy НЕ делались.
